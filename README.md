📊 Finance Analysis Dashboard | Power BI Project

I am pleased to share my latest Power BI project focused on financial transaction analytics and business performance monitoring.

The objective of this dashboard was to transform raw transaction data into meaningful insights that support data-driven decision-making. The report provides a comprehensive view of transaction performance, customer behavior, revenue distribution, fees, taxes, and regional trends through interactive visualizations and KPI tracking.

Key Business Insights

• Processed and analyzed 15,000+ transactions with a total transaction value of ₹135.62 Million

• Identified Retail as the highest contributing customer segment, generating approximately ₹74 Million in transaction value

• Maharashtra emerged as the top-performing state with over ₹19 Million in transaction volume

• Achieved an overall transaction success rate of 84.88%

• Loan EMI and Transfer transactions accounted for the largest share of transaction activity

• Monitored transaction fees, taxes, and average transaction values to evaluate operational performance
